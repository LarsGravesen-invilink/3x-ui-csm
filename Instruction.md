## 1. Что такое 3X-UI CSM

**3X-UI CSM** (CLI Subscription Manager) — это скрипт для Linux-сервера (VPS), который:

- Подключается к одной или нескольким панелям **3x-UI** через API
- Собирает **VPN-ключи** (VLESS, VMess, Trojan, Shadowsocks, Hysteria2) со всех или выбранных инбаундов
- Позволяет выбрать **конкретных клиентов** из конкретных инбаундов
- Объединяет всё в **один файл подписки**
- Раздаёт файл через **Nginx** по HTTP или HTTPS
- Может **автоматически обновлять** подписку по расписанию (cron)

**Результат:** Все ваши серверы с 3x-UI в одной подписке.

## 2. Требования

Перед установкой убедитесь что у вас есть:

| Требование | Описание |
|------------|----------|
| VPS-сервер | Ubuntu 20.04+ или Debian 11+ |
| Доступ SSH | Подключение по SSH с правами **root** |
| 3x-UI | Хотя бы одна панель версии **2.4.0+** |
| Свободные порты | **80** (для SSL), **443** (HTTPS) или **8443** (по умолчанию) |
Рекомендуется использования домена и SSL для корректной работы клиентов с подпиской.

## 3. Установка

### Шаг 1. Подключитесь к серверу по SSH

```bash
ssh root@ваш_ip_адрес
```

### Шаг 2. Запустите установку:

```Cкопируйте и вставьте в терминале:
curl -fsSL https://raw.githubusercontent.com/LarsGravesen-invilink/3x-ui-csm/main/3xcsm.sh -o /tmp/3xcsm.sh && chmod +x /tmp/3xcsm.sh && sudo bash /tmp/3xcsm.sh
```

### Шаг 3. Что происходит при установке

Скрипт автоматически:
1. Показывает экран приветствия с описанием
2. Ждёт нажатия **Enter** для продолжения
3. Показывает список компонентов, которые будут установлены
4. Проверяет и устанавливает все зависимости: curl, jq, nginx, cron, certbot, nano, qrencode, openssl
5. Создаёт директории и конфигурационные файлы
6. Запускает пошаговую настройку доступа к подписке

Скрипт также предупреждает о портах, которые должны быть свободны:
- **80** — для получения SSL-сертификата
- **443** — если используется домен с HTTPS
- **8443** — порт по умолчанию для раздачи подписки без домена

## 4. Первоначальная настройка

После установки зависимостей скрипт проведёт вас через 6 шагов настройки:

### Шаг 1 из 6: Домен

Скрипт спросит: **Использовать домен вместо IP для раздачи подписки?**

- Если у вас есть домен, направленный на этот сервер — введите `y` и укажите домен
- Если домена нет — введите `n`, подписка будет доступна по IP-адресу

### Шаг 2 из 6: Порт / Ввод домена

- При использовании IP: укажите порт (по умолчанию **8443**)
- При использовании домена: введите доменное имя (например: `sub.example.com`)

### Шаг 3 из 6: SSL (только для домена)

Скрипт предложит получить бесплатный SSL-сертификат от Let's Encrypt.
- Введите `y` для автоматического получения
- Домен должен быть уже направлен на IP этого сервера

### Шаг 4 из 6: Кодирование URL

Можно закодировать путь к файлу подписки, чтобы его было сложнее угадать.
- Обычный путь: `/sub.txt`
- Закодированный: `/aHR0cHM6Ly9leGFtcGxl...`
- Введите `y` для включения, `n` для отключения

### Шаг 5 из 6: Имя файла подписки

Укажите имя файла подписки **без расширения** `.txt` — оно добавляется автоматически.
- По умолчанию: `sub` (файл будет `sub.txt`)
- Можно указать своё: `mykeys`, `vpn`, `config`
- Пустой Enter — использовать значение по умолчанию

### Шаг 6 из 6: Конфигурация Nginx

Скрипт автоматически настроит веб-сервер Nginx для раздачи файла подписки.

### После установки

Вы увидите:
- Команду для запуска: `3xsub`
- URL подписки для VPN-клиентов
- Путь к файлу подписки

## 6. Пункт 1 — Добавить сервер с 3x-UI

### Что нужно подготовить заранее

- IP-адрес или домен вашей панели 3x-UI
- Порт панели (обычно **2053** для HTTPS или **2052** для HTTP)
- Логин и пароль от панели
- Web Base Path (если задан в настройках панели)

### Пошаговый процесс

1. **Название сервера** — любое имя для идентификации (например: `Germany-1`, `Finland`)
2. **IP-адрес или домен** панели
3. **Порт** — по умолчанию 2053
4. **HTTPS** — обычно `y` для 3x-UI v2.8+
5. **Web Base Path** — если задан в панели, ввести **БЕЗ слешей**. Если не задан — оставить пустым
6. **Логин** от панели (обычно: `admin`)
7. **Пароль** — ввод скрыт, пароль шифруется при сохранении

### После авторизации

Скрипт покажет список инбаундов с разбивкой по протоколам:

```
    0) ● [vless] VLESS │ :443 │ 5 кл.
    1) ● [vless] VLESS-KASKAD │ :8443 │ 1 кл.
    2) ● [vless] VLESS-DIRECT │ :9443 │ 2 кл.

    a) Выбрать ВСЕ
    0) ← Назад

  Номера через пробел (например: 1 2)
```

- **a** — выбрать все инбаунды
- **0 2** — выбрать только конкретные (номера через пробел)
- **0** — вернуться назад

### Выбор клиентов

После выбора инбаундов скрипт спросит, хотите ли вы выбрать конкретных клиентов.
Клиенты показываются с привязкой к инбаунду:

```
  [Инбаунд 1] VLESS [vless]
    0) Client-1
    1) Client-2

  [Инбаунд 9] VLESS-KASKAD [vless]
    2) Client-3

    a) Все клиенты
    Или номера через пробел
```

Подписка генерируется сразу после добавления сервера.

- **1** — новые инбаунды добавляются к ранее выбранным, старые сохраняются

```
    2) Удалить клиента из задания
```

#### Пункт 1 — Выбор клиентов

```
    1) Добавить к уже выбранным
    2) Использовать только новый выбор
```

- **1** — новые клиенты добавляются к ранее выбранным
- **2** — старый выбор клиентов заменяется новым

#### Пункт 2 — Удалить клиента

## 9. Пункт 4 — Редактирование заголовков / Настройка отображения

Заголовки — это метаданные в файле подписки, которые VPN-клиенты используют для отображения информации.

```
    1) Изменить название подписки
    2) Добавить флаги/эмодзи к названию
    3) Интервал обновления для клиента
    4) Ссылка поддержки / реклама
    5) Информация о трафике и сроке
    6) Включить/отключить заголовки
    7) Предпросмотр заголовков

    0) ← Назад
```

### Пункт 6 — Управление заголовками

Каждый заголовок можно включить или выключить отдельно:

| Заголовок | Что показывает в клиенте | По умолчанию |
|-----------|--------------------------|-------------|
| `#profile-title` | Название подписки | ✅ Включён |
| `#profile-update-interval` | Как часто клиент проверяет обновления | ✅ Включён |
| `#support-url` | Ссылка на поддержку | ❌ Выключен |
| `#profile-web-page-url` | Веб-страница подписки | ❌ Выключен |
| `#subscription-userinfo` | Трафик и срок действия | ❌ Выключен |

> ⚠️ Некоторые VPN-клиенты не поддерживают заголовки. Если возникают проблемы — отключите все или часть заголовков.

### Пункт 5 — Информация о трафике и сроке

Здесь можно настроить данные, которые отображаются в VPN-клиентах:

| Поле | Что означает | Как вводить |
|------|-------------|-------------|
| upload | Сколько трафика отправлено | В байтах |
| download | Сколько трафика скачано | В байтах |
| total | Лимит трафика | В гигабайтах (0 = безлимит) |
| expire | Дата истечения подписки | Формат YYYY-MM-DD или 0 |

## 10. Пункт 5 — Файл подписки / Редактирование

Информация о текущем файле подписки и управление им.

```
    1) Редактировать ключи
    2) Показать все ключи
    3) Скопировать URL
    4) Настройки домена и SSL
    5) Включить/отключить кодирование base64
    6) Включить/отключить кодирование URL
    7) Проверить доступность URL
    8) Показать QR-код подписки
    9) Изменить имя файла подписки
    10) Очистить файл подписки

    0) ← Назад
```

### Пункт 1 — Редактировать ключи

Открывает файл подписки в текстовом редакторе **nano**. Если содержимое закодировано в base64, оно автоматически декодируется перед редактированием. После сохранения кодируется обратно.

### Пункт 4 — Настройки домена и SSL

Позволяет:
- Переключить с IP на домен и обратно
- Включить/отключить SSL
- Изменить порт
- Включить/отключить кодирование URL-пути
- Изменить имя файла подписки

### Пункт 7 — Проверить доступность URL

Выполняет 3 проверки:
1. TCP-порт на localhost
2. Локальный HTTP-запрос
3. Внешний HTTP-запрос

Если обнаружена проблема — показывает причину и предлагает **авто-восстановление**.

### Пункт 8 — QR-код

Генерирует QR-код URL подписки прямо в терминале. Можно отсканировать камерой телефона.

### Пункт 9 — Изменить имя файла

Вводите **только имя без расширения** `.txt` — оно добавляется автоматически.
Пустой Enter — отменить изменение.

### Пункт 10 — Очистить файл подписки

Очищает содержимое файла подписки. Если включено автообновление — предупреждает, что файл будет перезаписан при следующем обновлении.

## 19. Безопасность

### Шифрование паролей

Пароли серверов хранятся в **зашифрованном виде** (AES-256-CBC).  
Ключ шифрования привязан к `machine-id` сервера — пароли нельзя расшифровать на другом сервере.

### Защита URL подписки

- Путь к файлу можно закодировать в base64
- Содержимое файла можно закодировать в base64
- Можно использовать HTTPS с автоматическим сертификатом Let's Encrypt

## 20. FAQ — Частые вопросы

### Подписка не открывается в браузере

1. Зайдите в **Файл подписки → 7) Проверить доступность URL**
2. Скрипт покажет причину и предложит авто-восстановление
3. Убедитесь, что порт открыт в firewall вашего VPS-провайдера

### Ключи не собираются с панели

- Проверьте версию 3x-UI (нужна 2.4.0+)
- Проверьте Web Base Path — вводить **БЕЗ слешей**
- Попробуйте переключить HTTP/HTTPS
- Запустите с отладкой: `DEBUG=1 3xsub`

### Выбранные клиенты не появляются в подписке

- Убедитесь что инбаунды выбраны правильно (пункт 8)
- Убедитесь что клиенты выбраны из правильных инбаундов (пункт 9)
- Проверьте через **Обзор состояния текущей подписки** (пункт 7)
- Попробуйте сбросить фильтры и выбрать заново

### Как добавить клиента к уже выбранным (а не заменить)

При выборе инбаундов или клиентов в режиме редактирования скрипт спрашивает:
- **1) Добавить к уже выбранным** — новый выбор добавляется к старому
- **2) Использовать только новый выбор** — старый выбор заменяется


### При вводе данных допустил ошибку — как отменить?

В любом поле ввода (имя файла, пароль, адрес и т.д.) — нажмите **Enter** без ввода данных, чтобы отменить действие и вернуться назад.
